# mimiga-ai-bot
# 🐿️ Mimiga AI Bot — Интерактивный Telegram-бот на базе DeepSeek API и PostgreSQL
Ролевой ИИ-ассистент и модератор групповых чатов с характером персонажа Момонги (*Chiikawa*), долговременной памятью на базе **PostgreSQL**, интеграцией нативного веб-поиска (**RAG / DeepSeek Search API**), системой кармы участников и встроенным набором **Smoke-автотестов** для самодиагностики в продакшене.
---

## Технический стек

* **Язык:** Python 3.10+
* **Telegram API:** `pyTelegramBotAPI` (`telebot`)
* **AI & LLM Интеграция:** OpenAI SDK / DeepSeek API (deepseek-flash с извлечением внутреннего монолога reasoning_content)
* **Web Search (RAG):** Прямая интеграция с `DeepSeek Native Search API` через `requests` для обогащения промпта актуальными данными из интернета в реальном времени
* **База данных:** `PostgreSQL` (`psycopg2`) — хранение истории контекста, профилей, системы кармы (с поддержкой паттерна *Soft Delete*) и медиагрупп (альбомов)
* **Тестирование и QA:** Встроенный модуль смоук-тестирования (`autotests.py`), регулярные выражения (`re`), санитизация HTML/Markdown-разметки и контроль граничных значений Telegram API
* **Инфраструктура:** Развертывание на Linux VPS (Ubuntu) под управлением `systemd`

## Архитектура проекта (Модульная структура)

Код проекта разделен на модули по зонам ответственности:

* **`main.py`** — точка входа и маршрутизатор событий Telegram: система безопасности (Whitelist-авторизация групп и фильтр личных сообщений), обработчики команд (`/autotest`, `/spletni`, `/itogi`, `/whois`, `/delo`), сборка медиа-альбомов и триггеры реакций.
* **`ai_service.py`** — сервисный слой работы с ИИ:
  * Ротация пула API-ключей (**API Key Rotation & Failover**) при ошибках лимитов (`402` / `429` / `5xx`) с экспоненциальной паузой.
  * Перехват и трансляция внутреннего монолога модели (`reasoning_content`) в канал логирования.
  * Пост-обработка и очистка текста от артефактов нейросети и незакрытых HTML-тегов перед отправкой в Telegram.
  * Модуль веб-поиска `search_deepseek_web()` для подгрузки свежих фактов, погоды и новостей.
* **`database.py`** — слой доступа к данным (DAO) для **PostgreSQL**:
  * Логирование истории сообщений для формирования контекстного окна диалога.
  * Система репутации и кармы (`OBIDA` / `DOBRO`) с реализацией мягкого удаления записей (`is_deleted BOOLEAN DEFAULT FALSE`).
  * Кэширование `file_id` фотографий из альбомов (`media_group_id`) для мультимодальных запросов.
* **`prompts.py`** — системные промпты, ролевые инструкции и динамические шаблоны генерации саммари чата (`/spletni`) и итогов дня (`/itogi`).
* **`autotests.py`** — встроенный **Smoke QA Suite** (вызывается командой `/autotest` с проверкой прав администратора), выполняющий 6 автоматических проверок на живом боте с выводом статус-репорта в Telegram:
  1. **`[DB Connection]`** — проверка соединения с БД PostgreSQL и выполнения тестового SQL-запроса (`SELECT 1`).
  2. **`[Regex Karma Parser]`** — проверка парсинга и вырезания скрытых системных тегов кармы (`[OBIDA: ...]` / `[DOBRO: ...]`) регулярными выражениями.
  3. **`[DeepSeek Chat API]`** — живой тестовый запрос к LLM (`ask_deepseek`) для проверки работоспособности пула ключей и генерации ответа.
  4. **`[DeepSeek Search API]`** — позитивное и негативное тестирование фильтра поисковых триггеров и проверка живого веб-поиска (`search_deepseek_web`).
  5. **`[Trigger 'ПОКА' & Sticker]`** — тестирование граничных значений регулярки (`\bпока\b`, чтобы бот не срабатывал на слово *«покажи»*) и тестовая отправка стикера через Telegram API.
  6. **`[Trigger 'ФУФЕЛ' & Asset]`** — проверка регулярки триггера `\bфуфел\b` и наличия привязанного медиа-ассета в конфигурации.
* **`config.py`** — конфигурация окружения (`os.getenv`), ролевые списки доступа (`VIP_USERS`, `VIP_CHATS`) и константы медиа-ассетов.

## Быстрый старт и установка

1. Клонируйте репозиторий и установите зависимости:
   ```bash
   git clone https://github.com/aakaloe/mimiga-ai-bot.git
   cd mimiga-ai-bot
   pip install -r requirements.txt
   ```

2. Настройте конфигурацию:
   * В файле **`config.py`** укажите токен вашего Telegram-бота (`TOKEN`), пул ключей DeepSeek (`DEEPSEEK_TOKENS`), списки доступа (`VIP_USERS`, `VIP_CHATS` и т.д.), а также ID технической группы/конфы для логов и автотестов (`LICHKA_CHAT_ID` и ID топиков).
   * Задайте переменные окружения для подключения к **PostgreSQL** (используются в `database.py`):
   ```bash
    export DB_NAME='chat'
    export DB_USER='postgres'
    export DB_PASS='ваш_пароль_бд'
   ```

3. Запустите бота:
   ```bash
   python main.py
   ```

4. Для запуска встроенной самодиагностики отправьте в чат/конфу с ботом команду:
   ```text
   /autotest
   ```
